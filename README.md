## Features

- **Buff Reminders**
  - Custom buff list by spell name or ID, with individual toggles.
  - Click to cast, drag to move, and optional sound for missing buffs.
- **Unit Frames**
  - Shared styling for player, target, focus, and target of target.
  - Health and power textures, borders, class colors, shadows, dimensions, and spacing.
  - Optional removal of native portrait art and configurable 2D or 3D side portraits.
  - Player buffs and matching target and focus auras, with adjustable size and spacing.
  - Target combo points, aligned PvP and level indicators, and combat text above the frames.
- **Texture Bars**
  - Independent textures for Blizzard health, power, and cast bars.
  - Individual toggles for supported player, target, focus, and target of target bars.
- **Action Bars and Cooldown Manager**
  - Shared icon styling for action buttons and Cooldown Manager icons.
  - Main, additional, pet, and stance bars, plus bag and micro menu styling.
  - Borders, class or custom border colors, rounded corners, icon finishes, zoom, opacity, scale, and text size.
  - Optional decorative art, keybinds, macro names, item counts, and charges.
  - Cooldown Manager keybinds mirrored from action buttons, including range colors.
  - Icon aligned cooldown shading and proc highlights.
- **Damage Meter**
  - Bar styles, textures, borders, class colors, and optional row icons.
  - Adjustable row height, spacing, text size, background opacity, and window opacity.
  - Lock and unlock from the options menu, with movement and resizing outside Edit Mode.
  - Saved window position, size, and lock state.
- **Chat**
  - Optional Lock and Unlock in the tab menu, drag by tab, and resize outside Edit Mode.
  - Saved window position and dimensions.
  - Optional selectable chat text for copying.
  - Optional chat history for up to 24 hours, stored by character and tab.
- **Nameplates**
  - Friendly and enemy nameplate styling where supported by the client.
  - Health bar textures, borders, selection highlight, and nameplate size.
  - Adjustable name text and level badge style, colors, size, position, and highlight.
  - Combo points on the target nameplate.
- **Personal Resource Display**
  - Bar textures, borders, spacing, size, width, heights, padding, and opacity.
  - Visibility modes, optional hiding at full health, and toggles for individual resources.
  - Class colored health, optional bar text, native health and mana abbreviations, and frequent energy text updates.

## Commands

- `/pt` or `/phalktools` — settings, with quick module toggles during combat.
- `/pt buffs` — buff reminder editor.
- `/pt copy` — selectable text from the current chat tab.
- `/pt cdm` and `/pt cdm debug` — Cooldown Manager keybind diagnostics.
- `/pt meter` — Damage Meter layout diagnostics.
